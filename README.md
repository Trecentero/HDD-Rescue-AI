# HDD Rescue AI

AI-assisted tools to diagnose, clone and recover data from failing hard drives.

## Problem
Hard drives fail without warning. Most people lose photos, work, family videos.

## What this project does
1.  **SMART Analysis:** Read SMART data and predict failure with AI.
2.  **Safe Cloning:** Guide to clone damaged drives with ddrescue without making it worse.
3.  **File Recovery:** Suggest best tool for each case (PhotoRec, TestDisk, etc).
4.  **Log Analysis:** AI reads ddrescue logs and tells you how bad it is.

## For who?
- People with a clicking drive
- Technicians in Costa Rica / LATAM
- Anyone who wants to save data without paying $500 to a lab
